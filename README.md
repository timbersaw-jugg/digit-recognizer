# Handwritten Digit Recognizer 🧠✍️

This Flask web app predicts handwritten digits using a trained CNN model on the MNIST dataset.

## Features
- Upload an image of a handwritten digit (28x28)
- Get real-time predictions
- Simple, clean UI
- ML model built with TensorFlow/Keras

## Tech Stack
- Flask (Python web framework)
- TensorFlow/Keras (model)
- OpenCV (image processing)
- HTML/CSS for frontend

## How to Run Locally
1. Clone this repo
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python app.py`
4. Open `http://127.0.0.1:5000` in browser

## Deploy on Render
- This app is Render-ready (see Procfile).
